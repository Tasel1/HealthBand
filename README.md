## 📌 О проекте

**HealthBand** — это доступный программно-аппаратный комплекс для непрерывного круглосуточного мониторинга состояния лежачих больных с трофическими язвами и хроническими ранами в хосписах и паллиативных отделениях.

### Актуальность проблемы:
- В хосписах медперсонал проводит плановый осмотр пациентов **2–3 раза в сутки**.
- Если воспалительный процесс начинается через час после обхода, патология остается незамеченной до **12 часов**, что ведет к развитию инфекции, некрозу и сепсису.
- **HealthBand решает эту задачу**: система фиксирует локальный очаг воспаления за **15 минут** (3 замера подряд по 5 минут) — **в 50 раз быстрее** планового обхода.

## 🔬 Аппаратная архитектура (Hardware)

Носимый модуль умной повязки на базе микроконтроллера с низким энергопотреблением (**BLE** / **Deep Sleep**) и четырьмя датчиками:

1. **Датчик температуры раны (NTC-термистор / цифровой датчик)** — фиксация локальной гипертермии раневого ложа ($\Delta T$).
2. **Опорный датчик температуры тела** — измерение базовой температуры пациента для отсечения системной лихорадки (ОРВИ) и случайного нагрева под одеялом.
3. **Датчик влажности раны (текстильный сенсор экссудата)** — контроль пропитывания повязки от 20% до 85% для предупреждения мацерации краев раны.
4. **Оптический пульсометр (PPG)** — мониторинг частоты сердечных сокращений (ЧСС) и гемодинамики больного.

### Сквозная цепочка передачи данных:
$$\text{Датчики повязки} \xrightarrow{\text{I2C/ADC}} \text{Микроконтроллер (Deep Sleep)} \xrightarrow{\text{Bluetooth LE}} \text{Шлюз палаты (Смартфон/Планшет)} \xrightarrow{\text{HTTPS}} \text{Облако (Google Sheets / PythonAnywhere)} \xrightarrow{\text{Web}} \text{Пост медсестры (HealthBand Web)}$$

## 💻 Возможности веб-платформы

Веб-приложение спроектировано по стандартам нативного дизайна **Apple Human Interface Guidelines (MacWhisper Light Theme)** без визуального шума:

1. **🏥 Клинический пост медсестры (Ward Bed Matrix)**:
   - Сводная матрица всех коек хирургического/паллиативного отделения.
   - Микро-индикаторы триажа (🟢 норма, 🟡 контроль экссудата, 🔴 острая инфекция).
   - Расчет температурного дифференциала $\Delta T = T_{\text{раны}} - T_{\text{тела}}$ в реальном времени.
   - Срочные действия в один клик: «Принять вызов», «Отметить смену повязки».

2. **📈 Интерактивная телеметрия и алгоритм тренда**:
   - Сглаженные графики динамики температуры, накопления экссудата и пульса.
   - **Алгоритм фильтрации ложных тревог (3-точечное подтверждение)**: система подтверждает тревогу только при стабильном росте температуры раны 3 замера подряд ($>37.5^\circ\text{C}$ и $\Delta T \ge +1.0^\circ\text{C}$), игнорируя кратковременное тепло от одеяла.

3. **🌐 Прямой шлюз Google Sheets (Live Data Stream)**:
   - Прямой коннектор к рабочей таблице проекта (`docs.google.com/spreadsheets`).
   - Автоматический поллинг каждые 30 секунд, индикатор онлайна и архив на 300+ измерений.
   - Офлайн-кэш для стабильной демонстрации без доступа к интернету.

4. **🧪 Интерактивный Demo Lab (Стенд для жюри)**:
   - Переключатель в шапке: `Google Sheets Live` ↔ `Demo Lab Симулятор`.
   - Готовые клинические сценарии в 1 клик:
     - *Нормальное заживление*
     - *Критическое промокание экссудатом (92%)*
     - *Острое бактериальное воспаление (+1.6°C)*
     - *Защита от ложного срабатывания (Тест с одеялом)*
   - Ручные слайдеры с мгновенной сквозной синхронизацией по всем экранам.

5. **🔔 Клиническая звуковая сигнализация**:
   - Мягкий больничный сигнал тревоги (hospital monitor chime) через Web Audio API.

6. **📑 Лист динамического наблюдения (Форма 004/у)**:
   - Врачебный протокол за смену с автоматическим заключением.
   - Кнопка чистой печати на лист А4 (`window.print()`).

7. **ℹ️ Сравнение со Стэнфордским университетом**:
   - Детальный бенчмарк с разработкой Стэнфорда (*Nature Biotechnology*, 2022).
   - Сравнение себестоимости: **~26 000 ₸** (~$55) против **>$1 500 – $3 000+**.

## 📊 Экспериментальные результаты

| Параметр | Условия проверки | Результат | Клиническая значимость |
|---|---|---|---|
| **Скорость реакции** | Имитация локального нагрева | Реакция за 5 мин, тревога за 15 мин | В 50 раз быстрее планового обхода |
| **Точность термометрии** | Сравнение с эталонным термометром | Погрешность $\pm 0.3^\circ\text{C}$ | Достаточно для выявления инфекции |
| **Контроль влажности** | Имитация выпота экссудата | Рост с 20% до 85% за 4 часа | Объективный сигнал к замене повязки |
| **Надежность канала** | Непрерывная передача 7 часов | 0% потерь пакетов (84/84) | Надежный сквозной мониторинг |
| **Автономность** | Режим Deep Sleep (95% сна) | 28+ часов (до недель от пауэрбанка) | Не требует частой подзарядки у койки |

## 🚀 Установка и запуск

### Требования:
- Node.js 18+
- npm 9+

### 1. Клонирование и установка зависимостей:
```bash
git clone https://github.com/Tasel1/HealthBand.git
cd HealthBand
npm install
```

### 2. Запуск в режиме разработки:
```bash
npm run dev
```
После запуска откройте в браузере: `http://localhost:5173`

### 3. Сборка для продакшна:
```bash
npm run build
```
Готовая статическая сборка будет сформирована в директории `dist/`.
